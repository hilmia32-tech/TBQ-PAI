# Download Aplikasi BTQ (SDN Jayasari)

File installer Android (.apk) telah siap:

- **Nama File**: `Aplikasi_BTQ.apk`
- **Lokasi Utama**: Di folder utama proyek (`/Aplikasi_BTQ.apk`)
- **Lokasi Build**: `/app/build/outputs/apk/debug/app-debug.apk`

### Cara Mengunduh Langsung:
1. Lihat panel **Explorer / Daftar File** di sebelah kiri layar.
2. Cari file **`Aplikasi_BTQ.apk`** yang berada tepat di folder paling atas (root).
3. Klik kanan pada file **`Aplikasi_BTQ.apk`** lalu klik **Download**.
4. Buka file APK di HP Android Anda untuk memasang aplikasi.
